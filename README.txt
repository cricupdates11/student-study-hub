# Student Study Hub PWA

## Install as an Android app
1. Upload the contents of this folder to a HTTPS host (GitHub Pages is free).
2. Open the hosted `index.html` in Chrome on Android.
3. Chrome menu (⋮) → **Install app** or **Add to Home screen**.
4. Launch from your home screen. The app caches its files for offline use.

## Data
The app's progress is stored in browser LocalStorage. Keep using the same browser profile and website origin. Export a backup from the app's settings before clearing browser data or changing devices.

## Files
- `index.html`: complete Study Hub
- `manifest.webmanifest`: app metadata
- `sw.js`: offline cache
- `icons/app-icon.svg`: app icon
